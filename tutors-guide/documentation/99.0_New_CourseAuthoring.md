### Part 1: File Structure & Naming Conventions

#### 1. The Directory Level Rule (Two-Level Invariant)

In `lib/contentLoader.ts`, `getAllAvailableTests` expects a strict **two-tier directory depth** beneath `content/tests/`:

```text
content/tests/<category_folder>/<test_id_folder>/

```

* **Level 1 (`category_folder`)** must correspond to a high-level category recognized by your route handlers and database enums (e.g., `act`, `ap_calc`, `gre`, `sat`, and `academic`).


* **Level 2 (`test_id_folder`)** is the unique identifier of the test (e.g., `diff-eq-ch1`, `sat-diagnostic-adaptive-1`).


* **Never add nested subfolders** inside the category level (e.g., do **NOT** do `content/tests/academic/diff-eq/ch1-test`). A 3-level folder structure will be ignored by `getAllAvailableTests`.



#### 2. Folder & File Naming Conventions

* **Category Directory (Level 1)**: Lowercase, snake_case or kebab-case matching the category slug (e.g., `academic`, `ap_calc`, `sat`).


* **Test Directory (Level 2)**: Must **exactly match** the `"id"` field specified inside `metadata.json`.


* *Example Folder:* `content/tests/academic/diff-eq-ch1/`
* *Inside `metadata.json`:* `"id": "diff-eq-ch1"`


* **Asset Directory**: If your test uses diagram images or formula sheets, place them inside an `assets/` subfolder and set `assetBasePath` accordingly:
```json
"assetBasePath": "/content/tests/<category_folder>/<test_id_folder>/assets"

```


* **Section Files**: Markdown files must match the `"file"` attributes listed in `metadata.json.sections` (e.g., `ch1-quiz.md` matching `"file": "ch1-quiz.md"`).

### Part 2: Step-by-Step: Adding a New Course & Test

Here is the complete walkthrough for adding a collegiate course like **Differential Equations (Chapter 1)**:

#### Step 1: Create the Test Directory and Markdown Question File

Under `content/tests/academic/`, create the folder `diff-eq-ch1/`:

```text
content/tests/
└── academic/
    └── diff-eq-ch1/
        ├── metadata.json
        └── ch1-first-order.md

```

Inside `ch1-first-order.md`, author the section frontmatter and questions:

```markdown
---
sectionId: "diff-eq-ch1-s1"
sectionTitle: "First-Order ODEs Mastery Quiz"
sectionOrder: 1
timeLimit: 3600
questions:
  - id: "diff-eq-q1"
    questionNumber: 1
    questionType: "MC"
    correctAnswer: "B"
    prompt: "Which of the following is an integrating factor for the linear equation $y' + 2xy = 4x$?"
    domain: "First-Order ODEs"
    skill: "Integrating Factors"
    difficulty: "Medium"
    options:
      - id: "A"
        text: "$e^{x}$"
      - id: "B"
        text: "$e^{x^2}$"
      - id: "C"
        text: "$2x$"
      - id: "D"
        text: "$\\ln(x)$"
    explanation: "The integrating factor is $\\mu(x) = e^{\\int 2x\\,dx} = e^{x^2}$."

  - id: "diff-eq-q2"
    questionNumber: 2
    questionType: "FR"
    correctAnswer: "3/2 | 1.5"
    prompt: "Find the value of $C$ satisfying the initial condition $y(0) = 1.5$ for $y(x) = Ce^{-x}$."
    domain: "Initial Value Problems"
    skill: "Separable Equations"
    difficulty: "Easy"
    explanation: "Evaluating at $x=0$ yields $1.5 = C e^{0} \\implies C = 1.5$."
---

```

### What Happens Automatically

Once those three files are saved, no additional code needs to be written:

1. **Auto-Discovery**: `getAllAvailableTests()` finds `diff-eq-ch1` under `academic` and displays it on the student dashboard under the Academic program tab.


2. **Database Sync**: The first time a student launches the test route (`/tests/academic/diff-eq-ch1/diff-eq-ch1-s1`), `ensureTestInDatabase(metadata)` automatically syncs the `Test` and `Section` records into PostgreSQL.


3. **Route Security**: The route guard checks `session.user.entitlements.includes("ACADEMIC:DIFF_EQ")` and blocks anyone who hasn't purchased the course.


4. **Scoring**: Submitting the section triggers `synthesizeExamComposite` with `ACADEMIC_PERCENTAGE`, displaying the student's raw percentage accuracy on their results dashboard.
